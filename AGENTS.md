# AGENTS.md

Situs statis demo (lima jenis usaha lokal) untuk https://devario.rioeka.com. Tanpa package manager, test, atau linter. Semua UI Bahasa Indonesia, data contoh (nama, harga layanan, alamat, nomor WA contoh) fiktif. Harga paket dan nomor WA pemilik adalah data asli.

## Struktur
- `tools/bangun/`: generator Python (tanpa dependency) yang menulis 23 berkas HTML di bawah. Berkas HTML adalah hasil generate: ubah sumbernya, lalu jalankan `python tools/bangun/build.py` dari root repo. Jangan edit HTML langsung, perubahan akan tertimpa. `css.py` = gaya dan tema, `data.py` = isi lima jenis usaha, `js.py` = status buka, alur pesanan, wizard, `build.py` = markup. Keluaran memakai CRLF dan idempoten. Folder ini tidak disalin ke image Docker.
- `index.html`: hub daftar lima jenis usaha (halaman utama, CSS dan JS inline). Harga paket asli (Rp 1.000.000 / 1.500.000 / 1.650.000, tahunan 300.000 / 500.000 / 600.000) ada di `PAKET` pada `build.py`, satu sumber untuk semua kartu. Seksi `#beda` ("Website sendiri, bukan website numpang") = konstanta `BEDA`. Nomor WhatsApp pemilik asli ada di `WA_PEMILIK` (dan `WA_PEMILIK_TAMPIL` untuk tampilan), dipakai tombol hub, seksi `#hubungi`, dan footer index. Teks perawatan tahunan = konstanta `PERAWATAN`.
- `{jenis}/index.html` untuk `salon`, `barbershop`, `spa`, `penginapan`, `katering`: halaman jenis berisi daftar 3 paket jenis itu, dibuat `halaman_jenis()`.
- `{jenis}/paket-{1,2,3}/index.html`: 15 halaman demo nyata. Masing-masing berkas mandiri (CSS inline, 1-2 `<script>` inline), tanpa shared stylesheet. Gaya bersama cukup diubah di `css.py`, lalu generate ulang. Identitas visual tiap jenis ada di konstanta `GAYA` (`css.py`), dipilih lewat atribut `<body data-j="{slug}">`: hero, deretan `.fakta` (dibuat `fakta()`, nilainya dihitung dari data), bentuk daftar harga, dan bentuk galeri berbeda per jenis. Spa dan penginapan menaruh galeri sebelum harga di paket-1 (`galeri_dulu` di `data.py`). Jenis baru: tambahkan blok `[data-j=slug]` di `GAYA`. Tiap halaman demo menegaskan "ini halaman demo": strip `.demo-strip` di atas header, kartu `.demo-kartu` (tabel "Di demo ini" ke "Di website Anda", dibuat `kartu_demo()`), label `.tag-anda` di tiap bagian (nama, harga, lokasi, galeri), dan penutup `penutup_demo()`. Teks-teks itu dibuat dari data `data.py`.
- Alur pesanan (`#pesan`, `#alur`) bercabang lewat `var D.mode`: `"jadwal"` (salon, barbershop, spa) memakai `BOOKING_JS`; `"inap"` (penginapan) dan `"pesan"` (katering) memakai `WIZARD_JS`. Paket-1 statis tanpa alur; paket-2 wizard 5 langkah; paket-3 wizard 6 langkah (tambah pembayaran). Wizard satu langkah per layar, tertutup sampai tombol "Mulai coba pesan" (`#pesan-buka`) atau tautan `#pesan` diketuk, progress bar, tombol Lanjut/Kembali lengket di `.aksi-langkah`, layar "Periksa" dengan tombol "Ubah" per baris.
  - Mode jadwal: layanan boleh dipilih lebih dari satu (checkbox, total harga dan perkiraan durasi diakumulasi). Tiap stylist punya daftar `bisa` (nama layanan yang dikerjakan) di `data.py`; stylist yang tidak mengerjakan semua layanan terpilih di-`disabled` oleh `selarasStylist()`, dan "Terserah, siapa saja" selalu aktif. Nama di `bisa` harus persis sama dengan nama layanan.
  - Mode inap: pilih kamar (radio), lalu stepper jumlah malam, dan stepper tamu (dewasa/anak) yang dibatasi `kap` kamar.
  - Mode pesan: stepper jumlah tiap menu dengan minimum order, pilih antar atau ambil sendiri, isi alamat serta jam bila antar (ongkos antar ikut dihitung).
- `404.html`, `50x.html`: halaman galat bertema index (hijau tua, aksen jingga), dibuat `halaman_galat()` di `build.py` (CSS `ERR` di `css.py`). Disajikan nginx lewat `nginx.conf` (`error_page`, 403 dipetakan ke 404, keduanya `internal`). 404 punya tombol "Kembali" (`history.back()` bila datang dari halaman situs sendiri, kalau tidak jadi "Ke beranda"). Keduanya `noindex`. Karena disajikan di path apa pun, semua link dan aset harus mutlak.
- `salon/index.html`, `barbershop/index.html`: kini halaman jenis biasa (bukan redirect lagi).
- `salon/img/g1-g6.jpg`, `barbershop/img/g1-g6.jpg`, `spa/img/g1-g6.jpg`, `penginapan/img/g1-g6.jpg`, `katering/img/g1-g6.jpg`: foto galeri paket-1 (720x540, Unsplash License, kredit di `.kredit` bagian galeri). Daftar file dan alt ada di `galeri` pada `data.py`. Foto ada di dalam folder jenis, jadi otomatis ikut image Docker. Pakai hanya foto Unsplash gratis (bukan Unsplash+), simpan lokal, jangan hotlink.
- Gaya butik (`gaya="butik"` di `SALON`, `data.py`): hanya salon. Mengaktifkan hero foto lengkung (`hero_foto`), judul serif Cormorant Garamond (`FONT_SERIF`, dimuat dan di-preload hanya untuk halaman butik), `GAYA_SALON` dan `GAYA_SALON_WIZARD` (css.py, ditaruh setelah `GAYA_UMUM` agar menang), dan memindah `kartu_demo()` ke bawah hero + fakta. Blok `[data-j=salon]` lama di `GAYA` tidak dipakai lagi oleh halaman butik (`GAYA_UMUM` memotongnya), tetapi tetap ada di `GAYA` supaya CSS jenis lain tidak berubah. Cormorant hanya untuk ukuran >= 24px dan berat >= 500.
- Gaya tenang (`gaya="tenang"` di `SPA`, `data.py`): hanya spa. Memakai jalur yang sama dengan butik lewat `GAYA_HALAMAN` di `build.py` (peta gaya ke CSS utama + wizard + font + preload): hero foto oval tegak (`hero_foto`), serif Cormorant berat 500, semua rata tengah, ranting daun (SVG mask) di atas `h2`, galeri bentuk batu, harga tengah, FAQ tanpa nomor. CSS = `GAYA_SPA` dan `GAYA_SPA_WIZARD` (css.py, setelah `GAYA_UMUM`). `THEME_SPA` punya `--serif` dan `--lengkung`. Foto hero spa = g4; urutan galeri g1, g6, g2, g3, g5, g4. Gaya baru: tambah entri di `GAYA_HALAMAN`.
- Gaya hajatan (`gaya="hajatan"` di `KATERING`, `data.py`): hanya katering. Jalur `GAYA_HALAMAN` yang sama: hero foto bertepi bergerigi (`hero_foto` = g1), serif Fraunces (`FONT_FRAUNCES`, dimuat dan di-preload hanya untuk halaman hajatan), stempel bulat di hero, `.fakta` berbentuk tiket bertakik, pita scallop kunyit di atas tiap `.bagian`, judul berikon tumpeng, daftar harga berbentuk nota (baris putus-putus + tiket harga), galeri campur (petak bulat + kartu pos), FAQ bernomor tanpa chevron. CSS = `GAYA_KATERING` dan `GAYA_KATERING_WIZARD` (css.py, setelah `GAYA_SPA_WIZARD`). Fraunces hanya untuk ukuran >= 22px dan berat >= 500 (opsz dikunci 72 saat unduh). Urutan galeri g3, g5, g2, g4, g6, g1. `GAYA_HALAMAN` kini 4-tuple `(css utama, css wizard, konstanta @font-face, nama berkas preload)`.
- `font/`: Archivo self-hosted, plus Cormorant Garamond (`cormorant-garamond-latin.woff2`, `cormorant-garamond-italic-latin.woff2`, OFL) untuk halaman butik dan tenang, dan Fraunces (`fraunces-latin.woff2`, `fraunces-italic-latin.woff2`, OFL, subset latin, opsz dikunci 72) untuk halaman hajatan (katering). Berkas Fraunces disaring lewat `@font-face` `FONT_FRAUNCES` di `css.py`. Archivo: Halaman memuat font lewat `@font-face` inline dengan URL mutlak `/font/archivo-latin.woff2`, jadi harus disajikan dari root domain; buka via `file://` tidak memuat font.

## Konvensi
- Semua halaman `noindex, nofollow`; `robots.txt` = `Disallow: /`. Jangan hapus.
- Link internal pakai path mutlak (`/salon/paket-2/`), bukan relatif.
- Tidak ada hex mentah bebas: pakai variabel CSS di `:root` (`--latar`, `--kartu`, `--tinta`, `--tinta-redup`, `--garis`, `--sinyal`, dst.). Satu aksen per halaman (`--sinyal`). Pengecualian: halaman katering menambah aksen kedua dekoratif `--kunyit*` (stempel, tiket harga, pita scallop, tanda hari ini) yang tidak dipakai untuk tombol/tautan/status. Teks di atas `--kunyit` memakai `--tinta`; teks kunyit di atas krem memakai `--kunyit-gelap`. Tema: salon terang rose (`THEME_SALON`), barbershop gelap amber (`THEME_BARBER`), spa `THEME_SPA`, penginapan `THEME_INAP`, katering `THEME_PESAN`, hub/jenis/404 hijau tua dengan aksen jingga (`INDEX_TOKENS` / `WARNA_INDEX`). `TEMA` dan `WARNA_TEMA` memetakan nama jenis ke tema. Hex hanya didefinisikan di blok tema di `css.py`.
- Mobile-first: target sentuh min 44px, kontras teks min 4.5:1 (cek ulang kalau warna tema diganti), hormati `prefers-reduced-motion`, tanpa scroll horizontal di 375px.
- Kalau menambah berkas/folder baru, tambahkan `COPY` di `Dockerfile`; hanya `index.html`, `404.html`, `50x.html`, `nginx.conf`, `robots.txt`, `salon/`, `barbershop/`, `spa/`, `penginapan/`, `katering/`, `font/` yang disalin ke image (`tools/` sengaja tidak).

## Menjalankan
```
docker build -t demo-rioeka .
docker run -p 8080:80 demo-rioeka
```
Alternatif tanpa Docker (path font mutlak tetap jalan): `npx serve .` atau `python -m http.server 8080` dari root repo.
